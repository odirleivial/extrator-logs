Monta o JSON no mesmo formato aceito pela API (schema/fields, blocos de inhabitant ou professionalOrganization, listas de e-mail/telefone/endereço, optins etc.). Campos "Automático" são preenchidos com valores gerados na hora (CPF, CNPJ, nomes, e-mails, telefones...); o endereço automático é aproximado, pois a base real de CEPs só existe no servidor.
Compara o formulário com os dados atuais do cliente e gera um JSON Patch (op/path/value): campos alterados viram replace, campos marcados que não existiam viram add e campos desmarcados que existiam viram remove. Itens de lista (e-mail/telefone/endereço) podem ser editados, removidos ou adicionados. Revise o payload antes de enviar.
