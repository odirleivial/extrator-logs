📝 Variáveis de Consulta
$LOJA
Código da loja
ex: 0019
$PDV
Número do PDV
ex: 192
$NSU
NSU da transação
 
$DATA
Data (YYYYMMDD)
ex: 20260627
SQL
SELECT * FROM transacoes WHERE loja_codigo = $LOJA AND pdv_numero = $PDV AND nsu = $NSU AND data_transacao = $DATA
📊 Fluxo de Dados
Solicitar Logs
  1. Seleciona Loja, PDV, Logs e E-mail
  2. Clica em "Solicitar Logs"
  3. Flask envia e-mail com PID
  4. Interface exibe PID para rastreamento
  5. Registro salvo em CSV de histórico
Exportar Oracle
  1. Seleciona filtros (Loja, PDV, NSU, Data)
  2. Escolhe formato CSV ou XLSX
  3. Marca as consultas desejadas
  4. Backend executa queries com variáveis
  5. Múltiplas consultas → compacta em ZIP

🆘 Troubleshooting
Cannot convert LOB to Excel
O código já trata LOBs automaticamente. Verificar se está usando a versão mais recente de extrator_logs.py.
Consulta não encontrada
Verificar se o nome da consulta está correto em config.properties e sem espaços extras.
Arquivo ZIP vazio
Verificar se as consultas retornam dados. Consultar log/extrator_logs.log para detalhes.
Conexão Oracle recusada
Verificar credenciais em secure.properties e disponibilidade do servidor Oracle.
