📚 Como configurar o Cloudflare Worker (fazer uma vez, válido para todas as máquinas)
  1. Acesse dash.cloudflare.com → Workers & Pages → Create
  2. Cole o código do arquivo cloudflare_worker/relay.js da pasta do projeto
  3. Em Settings → Variables, adicione: TOKEN = <seu token secreto>
  4. Em Settings → Variables → KV Namespace Bindings, crie um namespace chamado bec-relay e vincule com o nome de variável KV
  5. Salve e faça o deploy. Copie a URL gerada (ex: https://bec-relay.usuario.workers.dev)
  6. Cole a URL e o token nos campos acima e salve
  7. No agent.properties de cada PDV, configure:
    pinpad_modo_comunicacao=tunnel
    bec_tunnel_url=https://bec-relay.usuario.workers.dev
    pinpad_tunnel_token=<mesmo token>
